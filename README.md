# Offshore Energy Hubs - Stochastic Optimization

This repository contains the data and Python code developed for the continuation of the Bachelor's Thesis on **stochastic optimization of Energy Hubs** to **Offshore Energy Hubs** using Pyomo. It includes the implementation of deterministic and stochastic optimization models, scenario generation, performance assessment, and graphical visualization of the results.

## Repository overview

The project follows a modular workflow in which historical data are processed, transformed into stochastic scenarios, used to formulate and solve Energy Hub optimization models, and finally analysed through performance metrics and graphical visualizations.

## Repository structure

- **data/** – Input datasets, including processed historical data, model parameters and generated scenarios.
- **src/** – Core source code containing the Pyomo model formulations, input data loading functions and shared utilities.
- **run/** – Executable scripts used to solve the deterministic and stochastic Energy Hub optimization models.
- **outputs/** – Optimization results generated by the execution scripts (Excel files and other exported results).
- **metrics/** – Scripts for computing performance indicators such as Expected Value of Perfect Information (EVPI) and Value of the Stochastic Solution (VSS).
- **plots/** – Scripts for generating the figures and comparisons presented in the thesis.
- **study_cases/** – Images for the all the study cases considered in the thesis.

## Repository documentation

Each main directory contains its own `README.md` describing the purpose of its contents and how the corresponding scripts should be used.

For every Python script, the documentation includes:

- **Purpose** – Description of the script.
- **Inputs** – Required input files and datasets.
- **User-configurable parameters** – Variables that can be safely modified.
- **Outputs** – Generated files and results.
- **Dependencies** – Required modules or input files.
- **Execution order** – Position of the script within the overall computational workflow.

## Reproducibility

The repository has been organised to facilitate the reproducibility of the computational experiments presented in the thesis. All project paths are handled relative to the repository root, allowing the code to be executed on any machine without modifying file locations.

The repository can be reproduced by:

1. Cloning the repository.
2. Installing the required Python dependencies.
3. Running the desired scripts from the `run/` directory.
4. Executing the scripts in `metrics/` and `plots/` to reproduce the analyses and figures presented in the thesis.

## Software

The models have been developed in **Python** using **Pyomo** as the optimization modelling framework. Data processing is performed with **pandas**, representative scenarios are generated using **TSAM** (Time Series Aggregation Module), and **Matplotlib** is used for visualization.  

## Solver

All optimization models are implemented in **Pyomo** and solved using the **GLPK** (GNU Linear Programming Kit) solver.

Before running the execution scripts, ensure that GLPK is installed and accessible from your Python environment.

## Study cases

The different models studied in the thesis contain the following elements.

- **EH1** : A Transformer, a Converter Heat to Power, a Furnace, and an Absorption
Chiller.
- **EH2** : A Transformer, an ESS, a Converter Heat to Power, a Furnace, and an
Absorption Chiller.
- **EH3** : A Transformer, an ESS, an Electrical Heat Pump, a Converter Heat to
Power, a Furnace, and an Absorption Chiller.
- **EH4** : A Transformer, an ESS, an Electrical Heat Pump, a Converter Heat to
Power, a Furnace, an Absorption Chiller, and a H2 tank.
